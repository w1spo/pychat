## About

pychat is a lightweight command-line chat application built with Python and Firebase Realtime Database.

It provides a simple public chat experience directly from the terminal.

## Features

- Firebase Realtime Database
- Guest usernames
- Real-time messaging
- Image upload
- Image download
- Command-line interface
- Lightweight and simple

## Requirements

- Windows
- Python 3.14+
- Firebase project with Realtime Database
